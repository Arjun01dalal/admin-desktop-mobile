# @astro/mobile

Mobile client scaffold for the Astro platform.

## Status
Placeholder only. Choose Expo or React Native when product is ready.

## Rules
- Depend on `@astro/shared` for types / client codes
- Call backend over **HTTPS** with mobile secure storage for tokens
- Do **not** import `@astro/desktop` or any Electron main/preload code

## Start
```bash
# from repo root
npm run mobile:start
```
